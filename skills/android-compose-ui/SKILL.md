# Android / KMP Compose UI

Read the branch that matches the change:

- Screen structure, state ownership, recomposition, side effects, lazy layouts,
  deferred reads or TextField dispatching: [screen architecture](references/compose-architecture.md).
- Buttons, cards, dialogs, icons, previews, animation, modifiers or reusable design
  system composables: [component patterns](references/compose-components.md).
- Root/Screen contracts and ViewModels: use `android-presentation-mvi`.

Read both references when a change crosses screen architecture and component construction.
